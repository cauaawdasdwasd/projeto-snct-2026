# Arte opcional dos captchas

O jogo funciona sem estes arquivos (desenhos reserva em código). Quando eles existem, são usados sozinhos.
Os prompts para gerar cada um estão em `prompts_para_codex.md` na raiz do projeto.

| Pasta | Arquivos esperados |
|---|---|
| `tiles/` | `cat_01.png`..`cat_06.png`, `other_01.png`..`other_06.png` (256x256) |
| `verify9/` | `verify9_neutral.png`, `_suspicious`, `_angry`, `_happy` (512x512, transparente) |
| `invaders/` | `enemy_01_bug.png`, `enemy_02_virus.png`, `enemy_03_spam.png`, `enemy_04_bot.png`, `player_ship.png` (128x128) |
| `nelson/` | `nelson.png` (512x512, transparente) |
| `ads/` | `ad_gift.png`, `ad_pc.png`, `ad_rocket.png`, `ad_shield.png` (128x128) |
| `cards/` | `card_back.png` (256x288) |
| `portraits/` | qualquer `.png` de busto de cientista (1254x1254, transparente) |
