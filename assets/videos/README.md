# Tutoriais em vídeo

Coloque os tutoriais finais nesta pasta usando estes nomes:

- `grace_hopper.mp4`
- `katherine_johnson.mp4`
- `ada_lovelace.mp4`
- `radia_perlman.mp4`
- `fei_fei_li.mp4`
- `margaret_hamilton.mp4`

O quadro de vídeo já existe no popup de cada protocolo. A leitura de MP4 ainda não
está ligada, pois o `pygame-ce` não decodifica esse formato sozinho. Quando os vídeos
estiverem prontos, será possível escolher e implementar a biblioteca de reprodução
sem alterar o layout dos popups.
