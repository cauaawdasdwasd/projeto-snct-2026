# Web Button ver 2

Sprites fornecidos pela equipe na pasta `web button ver 2`. Os controles de
minimizar, maximizar e fechar usam as tres linhas de estados do arquivo
`web button.png`.

O material recebido nao inclui arquivo de licenca ou identificacao do autor.
Antes de distribuir o jogo publicamente, a equipe deve localizar a pagina
original do pacote e registrar aqui o autor e os termos de uso.
